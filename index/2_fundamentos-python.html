    Capítulo 2

    Comentarios: notas para humanos

    Imagina que estás leyendo un libro y haces anotaciones al margen con un lápiz. En programación, eso se llama Comentario.

    • Son notas de texto que escribimos para nosotros mismos o para otros programadores.
    • El computador ignora por completo estas líneas. No se ejecutan.
    • En Python, cualquier línea que comience con el símbolo de numeral (#) se convierte en un comentario.
    Capítulo 3

    La función print(): el megáfono

    Una computadora procesa millones de datos en silencio. Si queremos que nos muestre un resultado o nos dé un mensaje, necesitamos ordenarle que "hable".

    Para eso usamos print(). Es como el megáfono de tu programa. Todo lo que pongas dentro de los paréntesis (y entre comillas si es texto), aparecerá en la consola.

    ¡Inténtalo! Edita el texto entre comillas en el código de la derecha, pon tu propio nombre y presiona Ejecutar.
    Capítulo 4

    Variables: cajas de almacenamiento

    Imagina que te mudas de casa. Tomas una caja de cartón, metes unos libros dentro y le pegas una etiqueta que dice "Libros".

    En programación, la etiqueta es el nombre de la variable y los libros son el valor que guardaste.

    Reglas OBLIGATORIAS para nombrar cajas (variables):

    • NO pueden tener espacios: mi edad = 20 → mi_edad = 20 (Usa guión bajo).
    • NO pueden iniciar con números: 1_nombre = "Juan" → nombre_1 = "Juan".
    • Sensibles a mayúsculas: Edad y edad son dos cajas totalmente diferentes.
    • Sin caracteres especiales: Evita la ñ, tildes y símbolos (@, #, $).
    ¡Manos al teclado!

    Reto: Variables

    Utilizando el editor de abajo, escribe un programa que cumpla lo siguiente:

    1. Crea una variable llamada mi_nombre y asígnale tu nombre en texto (entre comillas).
    2. Crea una variable llamada mi_edad y asígnale tu edad (en números, sin comillas).
    3. Usa la función print() dos veces para imprimir ambas variables.
    Capítulo 5

    Condicionales: encrucijadas y decisiones

    Imagina que vas conduciendo y llegas a una bifurcación en el camino. Un letrero dice: "SI (if) el semáforo está verde, avanza. SI NO (else), detente."

    Los programas no son líneas rectas. Necesitan tomar decisiones basadas en datos. En Python usamos if y else para crear estos caminos condicionales.

    Operadores útiles:

    > (Mayor que) | < (Menor que)

    == (Es igual a) | != (Es Diferente a)

    ¡Manos al teclado!

    Reto: Condicionales

    1. Crea una variable llamada calificacion y asígnale un número de 0 a 100.
    2. Escribe un if / else: Si la calificación es 60 o más, haz un print("Aprobaste la materia").
    3. De lo contrario, haz un print("Reprobaste la materia").
    Capítulo 6

    Bucles: el trabajador incansable

    Imagina que el profesor te castiga y te dice: "Escribe 100 veces en el tablero: No debo llegar tarde". Puedes escribirlo a mano 100 veces, o puedes usar un bucle en Python y dejar que la máquina lo haga en 1 milisegundo.

    El bucle for se usa para repetir una tarea una cantidad específica de veces usando la orden range() (rango).

    ¡Manos al teclado!

    Reto: Bucles

    1. Escribe un bucle for que recorra los números usando range(1, 11).
    2. Dentro del bucle, imprime la palabra "Conteo:" seguida del número.
    Pista: print("Conteo:", variable_del_bucle)
    Capítulo 7

    Funciones: recetas de cocina

    Una función (def) es como una receta para hacer pan. Los parámetros son los ingredientes que le entregas (harina, agua), el bloque de código es el horno, y el return es el pan horneado que te devuelve.

    Las usamos para no tener que escribir el mismo código complejo una y otra vez. Primero definimos la receta, luego la llamamos cuando la necesitamos.

    Ejecuta primero la ventana 1 (definir) y después la ventana 2 (llamar). La segunda recuerda lo definido en la primera.
    1 · Definir la receta
    definir.py
    2 · Llamar la función
    llamar.py
    ¡Manos al teclado!

    Reto: Funciones

    1. Define una función def sumar_numeros(num1, num2):.
    2. Dentro de ella, crea una variable que sume ambos números y usa return para devolver el resultado.
    3. Llama a la función pasándole dos números de tu elección, e imprime el resultado.
    Capítulo 8

    Listas: mochilas de datos

    Ya sabemos que una variable es una caja para UN solo objeto. Pero, ¿y si necesitamos llevar muchos objetos, como en una mochila escolar? Para eso usamos las Listas (identificadas por corchetes []).

    Atención: Las computadoras son raras y empiezan a contar desde cero. El primer elemento de tu mochila está en la posición [0], no en la 1.

    ¡Manos al teclado!

    Reto: Listas

    1. Crea una lista llamada mis_colores que contenga tres colores en texto (ej. "Rojo", "Azul").
    2. Usa .append() para añadir un cuarto color.
    3. Usa print() para imprimir toda la lista.
