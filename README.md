## Sobre el curso

Material de clase del curso **Python + IA para Ciencia de Datos**. Incluye presentaciones, notebooks y conjuntos de datos utilizados durante las sesiones.

## Contenido del repositorio

- **`index.html`** — Página principal de la presentación del curso.
- **`index/`** — Páginas de cada sesión (inicio del curso, fundamentos de Python, perfil del docente).
- **`python/`** — Notebooks de Jupyter con el código trabajado en cada sesión.
- **`datos/`** — Conjuntos de datos utilizados en los ejercicios.

## Cómo usar este material

1. Abre la [presentación del curso](https://trabajocientifico.github.io/curso-python-ia-ciencia-datos/) para seguir las sesiones.
2. Descarga o clona el repositorio para ejecutar los notebooks localmente.
3. Los notebooks de la carpeta `python/` pueden abrirse en Jupyter, VS Code o Google Colab.
